Publishing Flow

Notion更新で育つ公開フロー

正本はNotion。公開はGitHub Pages。GitHubは中継。この前提を固定して、相談から公開までを追えるようにします。

  1. 01AIに相談する

    GPTやClaudeと壁打ちし、企画、設計、文章、実装方針を整理します。

  2. 02Notionに整理する

    公開してよい内容だけをCMSや各アーカイブに集約します。

  3. 03GitHubが同期する

    Actionsや手動作業でNotionの内容をサイト用ファイルへ変換します。

  4. 04履歴として残る

    何を変えたかがコミットやPRとして残り、後から振り返れます。

  5. 05サイトに反映される

    GitHub Pagesを通じて、活動内容や読み物として公開されます。
